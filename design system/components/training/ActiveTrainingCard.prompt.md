Black hero block on Главная — the highest-priority element. active: big done count + Продолжить; idle: Отметить посещение.

```jsx
<ActiveTrainingCard title="Техника и выносливость" statuses={st} currentStep="Лазание на выносливость" />
```

- Only one hero per screen.
- idle variant is the only place «Отметить посещение» is primary.
