Main action button. One orange primary per screen region; grey secondary for its sibling; black strong for "next" flows.

```jsx
<Button size="lg" icon="check" fullWidth>Выполнено</Button>
<Button variant="secondary" size="lg" icon="skip_next" fullWidth>Пропустить</Button>
```

- primary: orange — Выполнено, Продолжить тренировку, Сохранить.
- secondary: grey fill — Пропустить, Отмена, Изменить.
- strong: black — Следующий этап.
- outline: black 1.5px border — Завершить (header).
- danger: red text on bordered — Удалить все данные.
