# ClimbPass Design System

ClimbPass — личное офлайн-PWA для учёта посещений скалодрома и прохождения тренировочных программ. Человек открывает его на телефоне между подходами: чтобы найти текущую тренировку, прочитать задание, отметить этап и записать заметку.

**Источник.** Направление «Страва» (1b) из этого проекта: `ClimbPass Directions.dc.html` → `ClimbPass Страва.dc.html` (8 экранов). Внешнего кода, Figma и логотипа нет; все значения взяты из этих макетов.

## Продуктовая модель
- Один действующий абонемент: 1, 4 или 8 посещений. Посещение списывает один проход; начало и продолжение тренировки дополнительный проход не списывают.
- Посещение — без тренировки или с одной тренировкой. Две редактируемые программы; программа → разделы → этапы.
- Этап: не отмечен / выполнен / пропущен. Пропущенный не входит в «Выполнено».
- Этапы основной части: личная заметка + заметка из прошлого занятия.
- Офлайн, данные на устройстве. История: завершённые и незавершённые тренировки, отметки посещений.

## CONTENT FUNDAMENTALS
- Язык — русский. Регистр как в предложении; ВЕРХНИЙ только через CSS у оверлайнов («АКТИВНАЯ ТРЕНИРОВКА», «РАЗМИНКА»).
- Кнопки — глагол в инфинитиве: «Продолжить тренировку», «Отметить посещение», «Снять отметку», «Сохранить».
- Статус — факт с числами, без оценок: «Выполнено 4 из 9 этапов», «Осталось 5 из 8 посещений», «Действует до 30 ноября».
- Инструкции этапов — на «ты», повелительное наклонение, коротко: «Лезь плавно, следи за работой ног».
- Интерфейс к пользователю — на «вы» в системных текстах: «Вы на скалодроме?».
- Последствия называются до действия: «Отметка спишет один проход. Тренировку можно начать после — второй проход не спишется.»
- Статусы этапов — одно слово: «Выполнен», «Пропущен», «Сейчас», «Не отмечен». Тренировки: «Завершена», «Незавершена», «Идёт».
- Даты словами: «28 октября», в списках — день крупно + «ОКТ».
- Без эмодзи, восклицаний, мотивационных фраз, рейтингов, социальных и AI-элементов.

## VISUAL FOUNDATIONS
- **Характер:** спортивный, высококонтрастный, плотный. Белый фон, чёрная типографика, один оранжевый акцент. Без фотографий, иллюстраций, градиентов, стекла и размытия.
- **Цвет:** оранжевый `#F04E0E` — только главное действие, сегменты «выполнено», активная вкладка, текущий этап (подложка `#FFF1EA`). Текст-оранжевый — `#C2410C`/`#B23A0A` (контраст). Чёрный `#0F0F0F` — герой-блок, «сильные» кнопки, рамка поля. Серые `#F2F2F2`/`#EDEDED` — полосы разделов и вторичные кнопки.
- **Типографика:** один шрифт Onest (хорошая кириллица), веса 500/600/700/800. Цифры — 800 и `tabular-nums`; главное число на герое — 64px. Основной текст 16px / 1.5.
- **Сетка и отступы:** поля экрана 12px (главная/списки), 16px (тренировка/формы); padding карточки 20px. Шкала 2–28px.
- **Скругления:** умеренные — 2 сегмент, 8 чип, 10 поле, 12 кнопка, 16 карточка, 20 лист.
- **Карточки:** белые с рамкой 1px `#E3E3E3`, радиус 16, без тени. Главный блок — чёрная заливка. Вложенных карточек нет; раскрытый этап — во всю ширину, а не карточка в карточке.
- **Тени:** практически нет. Единственная — выбранный сегмент переключателя (`0 1px 3px rgba(0,0,0,.12)`). Иерархию дают заливка и толщина рамки.
- **Прогресс:** сегменты по числу этапов (8px на белом, 10px на чёрном), выполнено — оранжевый, пропущено — серый, не отмечено — светлый.
- **Статус** всегда = цвет + иконка + слово.
- **Hover:** затемнение заливки (оранжевый → `#DB430A`, серый → `#E2E2E2`), у прозрачных — серая подложка. **Press:** без сжатия. **Focus:** рамка поля становится оранжевой.
- **Анимация:** минимальная — `transform .22s ease` при возврате свайпа, `.3s` для заливки прогресса. Без пружин и появлений.
- **Жесты:** свайп раскрытого этапа вправо = выполнено, влево = пропуск, порог 90px; под карточкой открывается чёрный слой с подписью. Жесты дублируют видимые кнопки.
- **Фиксированные элементы:** нижняя навигация (не на экране тренировки), панель действий тренировки поднимается над клавиатурой. Учитываются безопасные зоны: 47px сверху, 34px снизу.
- **Затемнение:** только под листом снизу — `rgba(0,0,0,.5)`, без размытия.
- **Цели касания:** не меньше 48×48px; кнопки 56/60px, строки 56/68px.

## ICONOGRAPHY
- Один набор — **Material Symbols Rounded** (иконочный шрифт Google, подключается с CDN в `tokens/fonts.css`). Используйте компонент `<Icon name="…">` или класс `.cp-icon` с лигатурой.
- По умолчанию контурные; `FILL 1` — активная вкладка, статусные иконки, «play». Вес 400.
- Размеры: 16 (мета в строке), 18–20 (подписи), 22–24 (кнопки), 26 (навигация).
- Ключевые: home, list_alt, history, settings, arrow_back, close, check, check_circle, do_not_disturb_on, radio_button_unchecked, skip_next, play_arrow, flag, edit, add, drag_indicator, undo, repeat, timelapse, how_to_reg, cloud_off.
- Нет SVG-иллюстраций, PNG-иконок, эмодзи или юникод-символов вместо иконок.
- **Логотипа нет** — везде, где нужен знак, пишется «ClimbPass» шрифтом Onest 800, трекинг −0.03em.

## Fonts
- Onest (OFL) — переменный 400–800, лежит в `assets/fonts/` (cyrillic, cyrillic-ext, latin, latin-ext), `@font-face` в `tokens/fonts.css`.
- Material Symbols Rounded — с CDN Google Fonts (файл слишком большой для самостоятельного хранения).

## Index
- `styles.css` — точка входа (только @import).
- `tokens/` — `fonts.css`, `colors.css`, `typography.css`, `spacing.css` (отступы, радиусы, размеры, тени, движение), `base.css`.
- `components/`
  - `core/` — Icon, Button, IconButton
  - `forms/` — TextField, TextArea, SegmentedControl
  - `training/` — ActiveTrainingCard, MembershipStrip, ProgressSegments, Stat, SectionHeader, StepRow, StepCard, StatusLabel, ActionBar, HistoryRow
  - `navigation/` — TabBar, TopBar
  - `feedback/` — BottomSheet
  - `_card-boot.js` — помощник для карточек (бандл или компиляция исходников в браузере)
- `guidelines/` — карточки основ: цвета, типографика, отступы, бренд.
- `ui_kits/climbpass/` — кликабельный прототип приложения (главная, тренировка, программы, редактор, история, настройки).
- `SKILL.md` — для использования как Agent Skill.

## Intentional additions
Компонентной библиотеки-источника нет; набор выведен из макетов «Страва». `Icon` — обёртка над шрифтом иконок; `Stat` и `StatusLabel` выделены, потому что повторяются на нескольких экранах.
