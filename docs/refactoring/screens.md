Старые hash-ссылки не переименованы. «Тренировки» переименована в «Программы» только в подписи вкладки, дополнительно поддержан #programs.

## Общие состояния

Первичное открытие показывает загрузку до чтения IDB; непустая локальная история не заменяется пустой во время network pull. Пустые экраны содержат объяснение. Ошибка записи удерживает поле, даёт повтор/аварийную копию. Каждая вкладка имеет статус синхронизации с переходом в настройки либо конфликт: synced, local pending, offline, syncing, auth required, failure, conflict. Изменяемые экраны используют общий pipeline; readonly snapshots не предлагают правки до возобновления.

## Адаптации исходников

Сохранили модульный JS вместо прототипного React/Babel/CDN. Компоненты перенесены в функции HTML, общие tokens и native dialog. Демоданные и рисованный Device/клавиатура не используются. Реальная visualViewport управляет панелью, safe area берётся из env. Все цели не менее 48px; основные кнопки 56/60px. Формы длинные и не фиксированной высоты. Открытый этап во всю ширину, один за раз, переход только после успешной локальной записи; pending не превращён в четвёртый статус. Завершённые старые заметки любого типа показываются.

Onest и локальное подмножество Material Symbols (16 знаков) поставляются с лицензиями. Native modal dialog обеспечивает focus trap, Escape и возврат фокуса; основная кнопка — явное подтверждение, закрытие по умолчанию отменяет. Никаких новых глобальных reset/delete-account действий нет.

Отклонения с причиной:

- Заливка главной кнопки затемнена с #F04E0E до #CA420D для контраста белого текста; #F04E0E сохранён в сегментах. Акцентный текст #C2410C. На белом основной оранжевый не используется для мелких подписей.
- Сложный конфликт показан двумя полными JSON-редакциями с причиной, экспортом и выбором всей ожидающей ветки. На мобильном колонки складываются; это надёжная первая версия, но предметное сравнение отдельных полей остаётся улучшением UX.
- Дата в списках полностью словами с годом, вместо крупного дня с сокращённым месяцем прототипа: однозначность исторических записей. История группируется по месяцу/году.
- Native dialog вместо собственного focus-trap; снизу на мобильном, без имитации статус-бара/клавиатуры.
- Pull — полный атомарный снимок, без пагинации. API никогда не разрезает связанные изменения.

## Уточнение 03.11.2026: обслуживание вместо JSON-интерфейса

Пользовательских операций с файлами больше нет. #settings содержит аккаунт/синхронизацию/установку; #migration совместимо показывает настройки. Вход не предлагает скачивание исходных данных. Сравнение конфликтов отображает понятные поля вместо JSON и автоматически архивирует обе ветки локально. Однократный перенос history.json относится к процедуре обновления production, описанной в operations.md.
