# Карта экранов и дизайн

| Маршрут | Экран и состояния |
| --- | --- |
| `#home`, пустой hash | Главное активное занятие: прогресс и текущий этап. Старые дополнительные активные занятия — списком. Без занятия — посещение и остаток абонемента; без абонемента — форма |
| `#training`, `#programs` | Каталог действующих и архивных программ, план и дата последнего завершения |
| `#history` | Группы месяцев, фильтры, посещения без тренировки и абонементы; возврат сохраняет фильтр и позицию |
| `#settings` | Аккаунт, очередь, состояние синхронизации, повтор, вход/выход и установка |
| `#visit/:visitId` | Посещение без программы, активная или завершённая тренировка; отметки, заметки, завершение, возобновление и удаление |
| `#choose/:visitId` | Выбор программы для посещения |
| `#program/:programId[/:visitId]` | Просмотр и запуск программы, архив, редактор и версии |
| `#editor/:programId` | Черновик, разделы и этапы, перестановка, сброс и публикация |
| `#versions/:programId`, `#version/:versionId` | История публикаций, просмотр и восстановление новой версией |
| `#edit-pass` | Даты и лимит действующего абонемента, ошибки и подтверждение завершения |
| `#migration` | Совместимый переход в настройки |
| `#conflicts` | Причина, обе редакции в понятных полях, выбор ветки с автоматическим локальным архивированием |
| `#login/retry`, `#login/denied`, `#login/setup` | Ошибка входа, отказ в доступе или отсутствие настройки Google |

Подпись вкладки — «Программы»; старый маршрут `#training` сохранён. Пользовательского импорта, экспорта и восстановления файлов нет.

## Цвета и компоненты

- Акцент — `#FC5200`; текст и иконки на нём всегда белые.
- Вторичные поверхности и кнопки — `#F6F7F9`, текст и иконки на них — `#252C35`.
- Фон главного виджета на главной — `#252C35` со светлым содержимым.
- Шрифты Onest и локальное подмножество Material Symbols поставляются вместе с лицензиями.

Дизайн основан на прототипе `design system/ClimbPass Страва.dc.html`, адаптированном к ES modules, общим CSS-токенам и native dialog. Прототипы и UI kits — исходные материалы, а не актуальная реализация; при расхождениях действуют правила этого документа и пользовательская инструкция.

Цели нажатия не менее 48px, основные кнопки — 56/60px. Формы не имеют фиксированной высоты. Панели учитывают visualViewport и safe area. Этап раскрывается на всю ширину, одновременно открыт один этап; переход выполняется после успешной локальной записи. Native dialog удерживает фокус, поддерживает Escape и возвращает фокус после закрытия. Подтверждение завершения тренировки не содержит отдельной кнопки «Закрыть».

Новое посещение запрещено, пока есть активная тренировка; клиент и сервер проверяют это правило. Кнопки «Отметить ещё посещение» нет. Старые записи с несколькими активными занятиями сохраняются.

## Загрузка, сохранение и конфликты

Начальная загрузка завершается после чтения IndexedDB. Непустая локальная история не заменяется пустой во время сетевого pull. Ошибка записи удерживает введённый текст и предлагает повтор. Состояния синхронизации ведут в настройки либо к конфликту.

Конфликт показывает обе редакции обычным текстом. Перед выбором ветки приложение автоматически сохраняет обе редакции и очередь локально; скачивание JSON не требуется. Завершённый снимок занятия доступен для чтения, изменение требует возобновления.

Проверенные браузерные сценарии и границы проверки устройств описаны в [приёмке](acceptance.md).
